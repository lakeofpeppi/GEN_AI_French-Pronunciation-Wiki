# Multi-agent collaboration

**One line:** several agents split a task, often with a "PM" agent assigning work.

## Explanation
For big tasks, one LLM acts like a project manager: it splits the work and hands pieces to
other agents (one calculates, one searches, one analyzes), then combines the results.

## Key points
- Multiple AI agents work together on one task [L08 p.37]
- Often a PM-like LLM splits the task and assigns parts [L08 p.38]

## Example
PM agent: "Agent 1, compute the totals. Agent 2, look up the prices. Agent 3, write the summary."
