# Delegation (being a good "boss")

**One line:** hand an agent a task with a clear result, clear limits, and a clear way to check it.

## Explanation
Agents fail most when they have to guess. A good request says what output you want (and
where, in what format), what may and may not be changed, and how you'll judge it finished.

## Key points
- Three things to state: the result you want, the limits, and how to check it's done [L09 p.18]
- The same three become the first parts of a loop spec: goal, limits, done-criteria (plus stop and trigger) [L10 p.21]

## Example
"Sort my Desktop into folders by purpose. Don't delete anything. Show me the plan first,
then list every file you moved."
