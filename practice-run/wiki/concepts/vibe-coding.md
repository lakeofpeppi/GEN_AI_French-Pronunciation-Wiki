# Vibe coding

**One line:** describe what you want and accept the AI's code without reading it.

## Explanation
A term from Karpathy (Feb 2025): you "forget the code exists", accept every change and paste
errors back to the AI. It's fun and fast for throwaway projects, but risky for real ones.

## Key points
- Key habits: forget the code exists, don't check it, paste errors back, don't read diffs [L08 p.46]
- Vibe coding is not the same as AI-assisted programming [L08 p.47]
- Fine for weekend projects and prototypes [L08 p.50]
- Not suitable for production code [L08 p.51]

## Example
"Make the sidebar padding smaller" → Accept All, never look at the diff.
