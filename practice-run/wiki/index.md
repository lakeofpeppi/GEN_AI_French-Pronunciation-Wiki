## Concepts
- [[context-engineering]] — choosing what info and instructions go into the prompt
- [[rag]] — retrieve matching chunks, then answer from them
- [[memory]] — short-term (this chat) vs long-term (stored, retrieved)
- [[llm-wiki]] — an LLM-maintained personal wiki
- [[rules-file]] — AGENTS.md / CLAUDE.md, the agent's handbook
- [[ai-agent]] — model + harness that plans, uses tools and acts
- [[harness]] — everything around the model that lets it act
- [[reflection]] — draft, critique, revise
- [[tool-use]] — the LLM calls functions; results come back as JSON
- [[planning]] — think or plan before answering (e.g. chain-of-thought)
- [[multi-agent]] — several agents split a task, often with a PM agent
- [[vibe-coding]] — accept AI code without reading it; prototypes only
- [[delegation]] — state the result, limits and done-check when handing work to an agent
- [[loop]] — a spec that repeats make → check → fix until done or stopped
- [[graph]] — a workflow drawn in advance with fixed nodes, checks and return routes
- [[checks]] — program checks vs fresh-context AI review
