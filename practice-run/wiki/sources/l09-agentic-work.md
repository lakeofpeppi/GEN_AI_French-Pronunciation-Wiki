# L09 — 換你當老闆 (Now you're the boss: agentic work)

## What it covers
Moving from *asking* AI questions to *handing it work*: what a harness contains, how
products like Claude Code provide one, and what a good "boss" must tell an agent.

## Key points
- Recap of the formula: AI Agent = AI Model + Harness [L09 p.3]
- The model thinks (understands, plans, decides); the harness does (actually opens the file, reports the result back) [L09 p.14]
- In the earlier homework we built a harness ourselves: system prompt, Python functions as tools, error handling and retries [L09 p.15]
- A product harness has: a workspace (sandbox computer), skills (a folder + SKILL.md SOP), tools (files, terminal, browser, search), and a rules file read before each task [L09 p.16]
- Models are broadly similar; the harness decides how useful an agent is [L09 p.17]
- A good boss says three things: what result you want, what limits apply, and how to check it's done [L09 p.18]
