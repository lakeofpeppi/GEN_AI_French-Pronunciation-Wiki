# From chatbot to agent
- A chatbot answers once, from whatever is in your prompt.
- It doesn't know the background in your head.
- An agent takes a goal and does the work: plans, gathers data, tries, and iterates.
Notes: Open with the contrast. Ask: what would you need to add to ChatGPT to make it book a train for you?
