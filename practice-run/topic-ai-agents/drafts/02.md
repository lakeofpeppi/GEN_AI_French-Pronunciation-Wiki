# AI Agent = Model + Harness
- **Model** (the brain): understands, plans, decides.
- **Harness** (the equipment): actually runs things and reports results back.
- Models are broadly similar; the harness decides how useful an agent is.
```text
model:   "I want to open data.csv"
harness: opens it → returns contents
```
Notes: This is the course's core formula. Everything later is "harness engineering".
