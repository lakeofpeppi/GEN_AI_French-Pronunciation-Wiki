# Loops: make, check, fix, stop
- Without a loop, *you* are the loop: you keep spotting problems and typing fixes.
- A loop spec is written once and runs many rounds.
- It needs brakes: a hard limit such as 3 rounds, because loops cost money.
```bash
while :; do cat PROMPT.md | claude ; done   # the original one-line loop
```
Notes: Point out the one-line loop has no stop condition. That's the bug.
