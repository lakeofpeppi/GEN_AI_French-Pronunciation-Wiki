# Graphs: draw the flow in advance
- In a loop, the AI decides the next step.
- In a graph, *you* draw the steps and checks beforehand.
- Failures go back along routes you designed, to the step nearest the error.
- If big loops back to the start happen often, move the check earlier.
Notes: Analogy: a school application goes department → college → registrar, and a problem returns you to a specific office.
