# Pattern 2: Tool use
- LLMs are bad at precise calculation, live data and searching, so don't force them.
- Tell the model which functions exist, e.g. `quote_order(item, qty)`.
- The model asks for a call; your code runs it; the result comes back as JSON.
Notes: Emphasize the two LLM phases: deciding the call, then answering from the JSON.
