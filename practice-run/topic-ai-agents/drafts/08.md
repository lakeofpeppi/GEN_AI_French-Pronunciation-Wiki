# Worked example: the drink-shop agent
User: "I'd like 20 cups of barley tea."
1. **Plan:** this needs a price, so call a tool.
2. **Tool call:** `quote_order("麥茶", 20)`
3. **JSON back:**
```json
{"item_name": "麥茶", "quantity": 20, "unit_price": 30, "total": 600}
```
4. **Answer:** "No problem, 20 cups is 600 TWD."
