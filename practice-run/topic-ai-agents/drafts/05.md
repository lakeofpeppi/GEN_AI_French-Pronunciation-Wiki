# Pattern 1: Reflection
- One LLM writes a draft.
- A second LLM critiques it and suggests fixes.
- The first revises. Repeat a few times.
- The critic can be a different model.
```python
for _ in range(3):
    review = critic(draft)
    draft = writer(draft, review)
```
Notes: Same as how humans write: nobody gets an essay right in one pass.
