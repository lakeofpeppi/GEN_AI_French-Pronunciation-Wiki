# Feeding the model: context and RAG
- Give it correct information plus clear instructions.
- **RAG:** retrieve matching chunks of your documents, then put them in the prompt.
- RAG already counts as a simple agent: the computer finds the information itself.
```python
prompt = f"answer using {chunks}: {question}"
```
Notes: For CS students, RAG = nearest-neighbour search over embeddings + string templating.
