# Patterns 3–4: Planning and multi-agent
- **Planning:** ask the LLM to think or sketch a plan before answering.
- Chain-of-thought breaks a hard problem into steps.
- **Multi-agent:** a "PM" LLM splits the task and assigns parts to other agents.
Notes: Planning is one agent organizing itself; multi-agent is a team with a manager.
