# Read one sentence, step by step
**Ils parlent avec les amis.** (They talk with the friends.)
1. ils: final s silent before a consonant.
2. parlent: -ent is silent.
3. avec: c is pronounced (CaReFuL).
4. les amis: liaison, s becomes z.
🔊 Ils parlent avec les amis ≈ eel parl ah-vek lay-za-mee /il paʁl avɛk lezami/
Notes: Read it slowly, then at normal speed with the liaison glued on.
