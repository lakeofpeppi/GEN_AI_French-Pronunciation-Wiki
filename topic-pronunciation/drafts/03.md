# Rule 1: the end of a word is often silent
- Final consonants are usually silent.
- Except c, r, f, l, which are usually pronounced: remember **CaReFuL**.
- The verb ending -ent is always silent.
- ⚠ Sources disagree: -er words like parler break CaReFuL (the r is silent).
🔊 petit ≈ puh-TEE /pəti/
🔊 avec ≈ ah-VEK /avɛk/
🔊 parler ≈ par-LAY /paʁle/
Notes: CaReFuL is a rule of thumb, not a law. Learn each word's sound.
