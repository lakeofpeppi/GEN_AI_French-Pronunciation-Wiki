# Spelling vs sound

**One line:** French letters don't map one-to-one to sounds, but the patterns are learnable.

## Explanation
English speakers try to read French with English letter rules, which fails. French spelling
keeps many letters that are no longer pronounced, so you need to learn spelling *patterns*
and always pair a word with a spoken model.

## Key points
- Letters and sounds don't line up one by one. [S1 §Prononciation — Les bases] «French spelling and pronunciation do not correspond letter by letter»
- Learn with audio: read aloud, record yourself, repeat. [S1 §Prononciation — Les bases] «Use these patterns with a spoken model»
- Unlike English, French is predictable from spelling. [S2 §dear duolingo] «French pronunciation is actually predictable from spelling»

## Examples
- `parle / parles / parlent` all sound the same ≈ parl /paʁl/
