# IPA (International Phonetic Alphabet)

**One line:** one symbol per sound, so you can write pronunciation exactly, e.g. bon = /bɔ̃/.

## Explanation
Because French spelling hides the sound, dictionaries write words in IPA between slashes.
Each symbol is always the same sound. Beginners don't need all of them; the useful ones are
the sounds English lacks: /y/ (u), /ʁ/ (r), and the nasal vowels with a tilde, like /ɔ̃/.

## Key points
- A symbol key for French sounds. [S4 §Help:IPA/French] «It provides a set of symbols to represent the pronunciation of French in Wikipedia»
- The r is written /ʁ/. [S4 §Notes] «The French rhotic /ʁ/ is usually guttural (uvular)»

## Examples
- 🔊 `bon` ≈ bohn /bɔ̃/ · 🔊 `rue` ≈ rü /ʁy/
